# Vault 3 — Kaleidoscope Glyph (KGLYPH2)

Save your AI notes and rules as one small encrypted picture, then restore them later as a short prompt.
Everything runs in your own browser. No server, no account.

**Open it:** https://kvm-labs.github.io/vault/

Source, format guides and the Python version: https://github.com/KVM-Labs/Project-Kaleidoscope-KVMS-1.0 (folder `web-vault/kaleidoscope-glyph/`)
