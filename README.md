# KVM Labs website

Home page of KVM Labs, hosted with GitHub Pages at https://kvm-labs.github.io/

| Path | What it is |
| :--- | :--- |
| `/` | Home page |
| `/vaults/` | Vault Library: links to every vault |
| `/vault3/` | Vault 3, the Kaleidoscope Glyph tool (current) |
| `/vault3/versions/` | Version history: every saved version of Vault 3, each one a working page |
| `/vault/` | Short address: redirects to `/vault3/` |
| `/robots.txt`, `/sitemap.xml` | Tell search engines which pages to index (must stay in the root of this repository) |

Older vaults live in their own repositories and keep the same numbers as their addresses: `vault1` (first cockpit), `vault2`, `vault4` (WebGPU sandbox).
Project source and paper: https://github.com/KVM-Labs/Project-Kaleidoscope-KVMS-1.0
