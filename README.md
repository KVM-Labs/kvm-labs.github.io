# KVM Labs website

Home page of KVM Labs, hosted with GitHub Pages at https://kvm-labs.github.io/

| Path | What it is |
| :--- | :--- |
| `/` | Home page |
| `/vaults/` | Vault Library: links to every vault |
| `/vault-3/` | Vault 3, the Kaleidoscope Glyph tool (current) |
| `/robots.txt`, `/sitemap.xml` | Tell search engines which pages to index (must stay in the root of this repository) |

Older vaults live in their own repositories: `vault`, `vault2`, `vault-4`, `vault-5`.
Project source and paper: https://github.com/KVM-Labs/Project-Kaleidoscope-KVMS-1.0
